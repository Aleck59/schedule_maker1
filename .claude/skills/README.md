# Скиллы разработки

Скиллы Claude Code из [affaan-m/ECC](https://github.com/affaan-m/ECC) (коммит `b92f181`, лицензия MIT — `ECC-LICENSE`),
отобранные под стек проекта. Хуки и агенты ECC не подключены.

| Скилл | Зачем |
| --- | --- |
| `make-interfaces-feel-better` | Детали интерфейса: отступы, типографика, состояния, зоны нажатия |
| `frontend-design-direction` | Направление дизайна для рабочих экранов (дашборды, таблицы, формы) |
| `react-patterns` | Хуки, состояние, композиция компонентов React 19 |
| `frontend-a11y` | Доступность: формы, диалоги, вкладки, клавиатура |
| `accessibility` | Аудит доступности по WCAG 2.2 AA: контраст, размер целей, фокус, подписи |
| `design-system` | Аудит визуальной согласованности: токены цветов, типографики, отступов, оценка по 10 критериям |
| `click-path-audit` | Проверка пользовательских сценариев «кнопка → итоговое состояние» |
| `nestjs-patterns` | Модули, DTO, guards NestJS |
| `prisma-patterns` | Схема, миграции, транзакции Prisma |
| `postgres-patterns` | Индексы и запросы PostgreSQL |
| `python-testing` | pytest для модуля решателя и распознавания |
| `verification-loop` | Сборка, типы, линтеры, тесты и ревью diff перед коммитом |
| `tdd-workflow` | Сначала падающий тест, затем реализация |
| `benchmark-optimization-loop` | Измеримое улучшение генерации: базовая линия, гипотеза, замер |

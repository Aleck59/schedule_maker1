# 7. Интерфейс: страницы и компоненты

Код: `apps/frontend/src`. Все подписи и сообщения — на русском языке. Боковое меню показывает только разделы,
доступные роли пользователя (разделы «Работа», «Планирование», «Справочники», «Администрирование»; «Мастер
настройки» стоит первым, пока есть незавершённые шаги, затем уходит в «Администрирование»); маршруты дополнительно
защищены на клиенте и на сервере. При нехватке прав — пояснение и кнопка «На главную» / «Моё расписание»; для
ненайденной записи — кнопка возврата вместо бесполезного «Повторить».

Принципы: плотный, спокойный рабочий интерфейс — у записи одна-две строки без повторов, обычное состояние
приглушено (например, «обучается», «доступна»), цветом выделяется только то, что требует внимания; второстепенные
параметры свёрнуты; без горизонтальной прокрутки страницы на телефоне (широкие таблицы прокручиваются внутри блока).

## Страницы

| Маршрут | Страница | Роли | Содержание |
| --- | --- | --- | --- |
| `/login` | Вход | все | Форма входа, демонстрационные учётные записи |
| `/setup` | Мастер настройки | админ, диспетчер | Десять шагов от настроек организации до публикации: что сделано, что осталось, кнопка следующего действия. На страницах шагов (ссылки с `?guide=1`) — подсказка «Шаг N из 10» и переход к следующему шагу; прогресс виден в меню и на главной |
| `/` | Главная | все | Персонал: кнопка «Составить расписание для всех групп», полоса чисел дня (занятий сегодня, групп, преподавателей, аудиторий), «Требует внимания» — только ненулевые: конфликты, дефицит часов, отработки, отмены, перегрузка (или «всё в порядке»), выполнение плана, занятия по дням недели, загрузка аудиторий, отстающие дисциплины, перегрузка преподавателей, периоды. Преподаватель: сегодня, неотмеченные занятия, нагрузка. Студент: сегодня, завтра, изменения |
| `/my` | Моё расписание | преподаватель, студент | Недельная сетка или список по дням (удобно на телефоне), PDF; преподаватель указывает свою доступность и гибкие правила |
| `/schedule` | Расписание | персонал, преподаватель | Виды «группа», «преподаватель», «аудитория», «день» (все группы), «месяц»; перетаскивание с проверкой конфликтов; добавление занятия по клику на ячейку; массовое редактирование; проверка и публикация; окно «Устранение конфликтов» с вариантами исправления и автоисправлением; экспорт PDF/Excel и «Снять с публикации» — в меню «Ещё» |
| `/generation` | Составление расписания | админ, диспетчер | По умолчанию «Все группы»: дата семестра, уровень (СПО и ВО), интервал «с даты / по дату» и кнопка «Составить расписание»; режим, решатель, лимиты и мягкие ограничения свёрнуты в «Дополнительно» со сводкой. «Что будет составлено» — счётчики, состав по кнопке; для одного плана — период, группы, «Хватит ли времени» (только группы, требующие внимания). Результат: «поставлено N из M» с прогрессом, окна и поздние пары одной строкой, «Применить»; вкладки «Не поставлено» (по причинам, внутри — по преподавателям с раскрытием дисциплин), «По группам», «Просмотр», «Подробнее» (мягкие ограничения, предупреждения, журнал); предыдущие запуски компактным списком |
| `/hour-control` | Выполнение часов | админ, диспетчер, руководитель | Фильтры, сводка одной строкой («проведено N из M ч», прогноз, не хватает в расписании), статусы-фильтры, таблица дисциплин в одну строку (разница: −дефицит / +превышение, выполнение в %) с раскрытием по видам занятий, разрезы (группы, дисциплины, преподаватели, семестры, программы, СПО / ВО, организация) с графиком, Excel |
| `/makeup` | Отработки | админ, диспетчер, преподаватель | Задачи «требуется отработка», подбор свободного слота, постановка в расписание |
| `/programs/import` | Импорт учебного плана со скана | админ, диспетчер | Загрузка скана, фото страниц или цифрового PDF, ход распознавания; проверка в четыре шага: сведения титульного листа (уровень образования определяется по коду), календарный график (сетка недель с исправлением «кистью», семестры, периоды), дисциплины и часы по семестрам (исправленные и сомнительные ячейки подсвечены, при наведении — фрагмент скана; отметка «по выбору» для дисциплин по выбору и факультативов), создание плана и группы |
| `/programs`, `/programs/:id` | Учебные планы | персонал | Список планов с уровнем образования и фильтром «СПО / Высшее образование», создание плана и специальности (направления подготовки); дерево плана по циклам с часами по семестрам, редактор часов элемента (с предупреждением о неполных парах), семестры, группы, импорт Excel и шаблон |
| `/calendar` | Календарный график | персонал | Недели по курсам с типами (редактирование кликом), периоды и события (каникулы, практики, праздники, отпуска), экзамены и зачёты с автораспределением |
| `/workload` | Нагрузка | персонал | «По группам»: группа и её семестр (по умолчанию текущий), поиск, фильтр «Без преподавателя», «Сформировать по плану»; одна таблица — дисциплина и часы (Л · П · Лаб), занятия (вид, подгруппа; «все виды» приглушены), преподаватель прямо в строке (только допустимые по уровню группы), особенности (темп, поток, аудитория, превышение), изменить / удалить / разделить. «По преподавателям»: текущие семестры всех групп СПО и ВО — план, в расписании, проведено, пары на неделе и лимит, недели с перегрузкой, группы и дисциплины |
| `/groups`, `/groups/:id` | Группы | персонал | Список (уровень и форма обучения, режим занятий) и карточка: расписание, выполнение часов, подгруппы и студенты, нагрузка; режим занятий — учебные дни и допустимые пары |
| `/teachers`, `/teachers/:id` | Преподаватели | персонал | Плитки: фото (или инициалы), ФИО, должность, учёная степень и звание, образование, «Может вести» (СПО, бакалавриат…), дисциплины, число групп и ограничений; поиск по ФИО и дисциплине, фильтры по должности, уровню, кафедре и статусу. Карточка: фото (загрузка), квалификация, период работы; вкладки «Дисциплины» (по дисциплинам и группам с часами и кнопкой «Передать» с даты), «Расписание», «Ограничения» (кому может вести, период работы и лимиты, гибкие правила — дни, время, недели, онлайн, — отпуска и курсы, сетка доступности), «Нагрузка» |
| `/classrooms`, `/classrooms/:id` | Аудитории | персонал | Список с фильтром по типу, карточка: расписание, тепловая карта занятости, доступность |
| `/reports` | Отчёты | персонал, преподаватель | 12 отчётов с параметрами, таблица, Excel и PDF (преподавателю — отчёт по своему расписанию) |
| `/notifications` | Уведомления | все | Изменения расписания, публикация |
| `/settings` | Настройки | админ, диспетчер | Правила расписания и веса мягких ограничений, звонки, организация, журнал изменений (изменять может администратор) |
| `/users` | Пользователи | админ | Учётные записи, роли, связь с преподавателем или группой, блокировка |

## Ключевые компоненты

| Компонент | Назначение |
| --- | --- |
| `ScheduleGrid` (`components/schedule/week-grid.tsx`) | Сетка «пары × дни» или «пары × группы»; DnD Kit: перетаскивание карточек, подсветка целевой ячейки, блокированные дни (праздники, каникулы) |
| `LessonCard` | Карточка занятия: дисциплина, вид (цвет), подгруппа, преподаватель или группа, аудитория, статус, метки «1 ч», «закреплено», «перенос», «замена» |
| `LessonDialog` | Карточка занятия с действиями: отметить проведение (полностью, частично, заменяющим), перенести (с подбором слотов), замена, отмена (с причиной и отработкой), изменить, копировать, история, удалить |
| `CreateLessonDialog` | Дополнительное занятие с проверкой конфликтов до сохранения |
| `MonthView` | Месячный календарь (FullCalendar) |
| `IssuesList` | Список ошибок и предупреждений проверки |
| `EntityWeekSchedule` | Недельное расписание группы, преподавателя или аудитории в карточках справочников |
| `AvailabilityEditor` | Сетка доступности: доступно / предпочтительно / нежелательно / недоступно; в заголовках — время пар |
| `AvailabilityRules` | Гибкие правила доступности: «не может», «только», «желательно», «нежелательно», «онлайн»; шаблоны («последняя суббота месяца», «1-я неделя месяца — онлайн»), предпросмотр ближайших дат |
| `ConflictFixesDialog` | Варианты устранения конфликтов с применением в один клик и автоисправлением |
| `Stepper`, `GuideBar` | Шаги мастеров (импорт плана) и подсказка мастера настройки на страницах |
| `DataTable` | Таблицы на TanStack Table: сортировка, поиск, постраничный вывод |
| `SimpleSelect`, `Field`, `Confirm`, `StatCard`, `PageHeader` | Общие элементы форм и страниц (shadcn/ui, Radix) |

## Технические решения

- Данные — TanStack Query (кэш, фоновое обновление, опрос хода генерации), формы — React Hook Form + Zod с
  сообщениями на русском.
- HTTP-клиент автоматически обновляет access-токен по refresh-токену; при ошибке `409` из ответа извлекаются
  конфликты и показываются пользователю.
- Состояние страницы расписания (период, вид, неделя, сущность) хранится в URL — ссылкой можно поделиться.
- Тёмная тема, адаптивная вёрстка (мобильное меню, список занятий вместо сетки на телефоне), ленивые страницы
  (разделение кода по маршрутам).

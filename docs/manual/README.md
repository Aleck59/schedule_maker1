# Руководство пользователя

Подробная методичка по работе с программой «Расписание СПО и ВО»: от первой настройки колледжа до ежедневной
работы с расписанием. Рисунки сняты на демонстрационных данных (вымышленный «Колледж цифровых технологий»), поэтому
названия групп, ФИО и цифры у вас будут другими.

## Порядок работы в одном абзаце

Настройте организацию и звонки → заведите учебные планы (проще всего — загрузить файл .plx/.xml из программы «Планы», скан или Excel) → проверьте
календарный график и праздники → создайте группы, преподавателей и аудитории → распределите нагрузку → нажмите
**«Составить расписание для всех групп»** → разберите то, что не поставилось, и примените результат → нажмите
**«Проверить»**, устраните ошибки → **«Опубликовать»**. Дальше — ежедневные отметки, переносы, замены и отработки,
а контроль часов и отчёты всегда под рукой.

Этот же порядок ведёт **Мастер настройки** (пункт меню в самом верху): он показывает, что уже сделано и что
осталось.

# 11. Частые вопросы и решения

## Составление

**Поставилось не всё. Это ошибка?**
Нет. Генератор никогда не нарушает жёсткие правила (накладки, недоступность, календарь), поэтому, если места не
хватает, часть пар остаётся непоставленной. Откройте вкладку «Не поставлено» — там причина и быстрые исправления
([6.4](06-sostavlenie.md#64-не-поставлено-что-делать)).

**Больше всего пар не поставлено по причине «Не хватает аудиторий».**
Аудиторий меньше, чем групп, занимающихся одновременно. Варианты: добавить аудитории (в том числе «Онлайн»),
проверить, что вместимость указана верно (группа на 25 человек не встанет в кабинет на 20), разрешить поздние
пары или 5 пар у группы в день, перевести часть групп во вторую смену (режим занятий группы), объединить общие
лекции в потоки.

**Физкультура стоит в обычных кабинетах (или не ставится вовсе).**
У дисциплины в учебном плане укажите «Требуемые типы аудиторий» → «Спортивный зал» и заведите аудиторию этого
типа ([3.2](03-plany-i-grafik.md#32-карточка-учебного-плана)). Если несколько групп занимаются вместе — создайте
поток ([5.3](05-nagruzka.md#53-потоки)).

**«Преподаватель не назначен».**
Нагрузка → группа → строки «не назначен» (кнопка «Без преподавателя: N») → выберите преподавателя.

**Преподавателя нет в выпадающем списке нагрузки.**
Он не может вести у групп этого уровня (например, бакалавр — у бакалавриата) или неактивен. Проверьте
образование, степень и «Может вести» в его карточке ([4.2](04-spravochniki.md#42-преподаватели)).

**Группа не попала в «Что будет составлено».**
У неё нет семестра, идущего в выбранную дату: проверьте «текущий семестр» группы и даты семестров в учебном
плане. Причина пропуска видна в «Показать состав».

**Хочу пересоставить, но сохранить то, что уже поставил руками.**
Закрепите эти занятия («Изменить» → «Закрепить» или массовое редактирование → «Закрепить») и составляйте
с включённым «Заменять ранее составленные занятия» — закреплённые, ручные и проведённые занятия не трогаются.

**Генерация идёт долго.**
Для 50–60 групп 1–3 минуты — норма. Уменьшите «Лимит времени» или выберите решатель «Эвристика (быстро)». Можно
уйти со страницы — результат сохранится.

## Расписание

**Не нажимается «Опубликовать».**
В проверке есть ошибки (красные). Нажмите «Проверить» → «Как исправить» → «Исправить всё автоматически»; то, что
осталось, поправьте вручную ([7.4](07-raspisanie.md#74-проверка-и-устранение-конфликтов)).

**Перетащил пару, а она не встаёт.**
В новом месте конфликт: занят преподаватель, группа или аудитория, или день нерабочий. Программа покажет, что
именно. Воспользуйтесь «Перенести» → «Подобрать свободный слот».

**Студенты не видят расписание.**
Расписание в статусе «Черновик» — опубликуйте его. Или учётная запись студента не связана с группой
(Пользователи → студент → группа).

**Нужна бумажная версия для стенда.**
Расписание → «Ещё» → «Печатная форма на неделю…» → PDF для печати ([7.6](07-raspisanie.md#76-печать-и-выгрузка)).

**Поменял звонки, а у занятий старое время.**
Изменение звонков не трогает уже созданные занятия. Пересоставьте расписание «С даты».

**Праздник появился после составления.**
Добавьте его в «Праздниках» — календарь пересчитается, а проверка расписания покажет занятия в этот день
ошибками. Перенесите их через «Как исправить» или пересоставьте «С даты».

## Часы

**В контроле часов «Дефицит», хотя всё проведено.**
Посмотрите разницу: если не хватает «В расписании» — часть пар не поставлена или отменена без отработки. Если
проведено меньше — есть неотмеченные или частично проведённые занятия. Раскройте строку — там виды занятий и
«не отмечено / отменено».

**Нечётное число часов — что будет?**
Последнее занятие станет неполной парой на 1 час (метка «1 ч»). Часы не теряются ([9.1](09-kontrol-i-otchyoty.md#91-как-считаются-часы)).

**Преподаватель заболел на две недели.**
Карточка преподавателя → «Ограничения» → «Отпуск, курсы, больничный» с галочкой «Перенести пары… после выхода»
или оформите замены ([8.5](08-ezhednevnaya-rabota.md#85-отпуск-больничный-курсы-преподавателя)).

**Хочу свой логотип и название колледжа в программе.**
Настройки → Организация → «Название и логотип программы» ([2.2](02-podgotovka.md#22-организация)).

**Есть файл учебного плана из «Планов» (.plx) или GosInsp (.xml).**
Загрузите его в «Учебные планы → Загрузить скан плана» — это точнее и быстрее скана ([3.3](03-plany-i-grafik.md#33-импорт-плана-из-файла-plx-xml-или-со-скана)).

## Учётные записи

**Забыл пароль.** Администратор: Пользователи → пользователь → новый пароль.

**Сотрудник уволился.** Заблокируйте учётную запись; в карточке преподавателя укажите «Работает по»; передайте
дисциплины другому («Передать»).

## Словарь

| Термин | Значение |
| --- | --- |
| Академический час | 45 минут (настраивается) |
| Пара | 2 академических часа |
| Неполная пара | Занятие на 1 час при нечётном числе часов |
| Окно | Пустая пара между занятиями в один день |
| Поздняя пара | Пара с номером «поздняя пара начинается с №» и позже |
| Подгруппа | Часть группы для лабораторных и иностранного языка |
| Поток | Общая пара нескольких групп у одного преподавателя |
| Период расписания | Расписание одного семестра одного учебного плана |
| Черновик / публикация | Черновик видят только диспетчеры; опубликованное — все |
| Закреплённое занятие | Не меняется при пересоставлении |
| Отработка | Занятие, возвращающее часы отменённого |
| Жёсткое ограничение | Не нарушается никогда (накладки, недоступность, календарь) |
| Мягкое ограничение (пожелание) | Генератор старается соблюдать; сила задаётся весом |

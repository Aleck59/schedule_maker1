## Критерии готовности

- Демонстрационные данные (09.02.07, ИСП-24-1 и ИСП-25-1) генерируются без ошибок проверки, расписание публикуется.
- Все проверки CI проходят: линтеры, типы, модульные и e2e-тесты, тесты решателя, сборка образов.
- Стек поднимается одной командой `docker compose up -d --build`.

## Возможное развитие

- Запросы преподавателей на изменение расписания с согласованием диспетчером.
- Одновременное составление расписания нескольких периодов и групп с общими ресурсами колледжа (приоритеты групп).
- Импорт учебных планов из файлов «Планы» (.plx, Excel) и экспорт в электронный журнал.
- Подписка на календарь (iCal) для преподавателей и студентов, push-уведомления, Telegram-бот.
- Совмещение корпусов с учётом времени переезда; распознавание рукописных пометок на сканах.

# 6. API

REST API под префиксом `/api`, формат JSON, даты — `YYYY-MM-DD`. Интерактивная документация Swagger:
`/api/docs`. Таблица ниже сформирована по контроллерам (154 метода); роли проверяются на сервере.

## Общие правила

- **Аутентификация**: `POST /api/auth/login` → `accessToken` (15 мин) и `refreshToken` (7 дней); запросы с заголовком
  `Authorization: Bearer <accessToken>`; обновление — `POST /api/auth/refresh`.
- **Ошибки** — единый формат на русском языке:

  ```json
  { "statusCode": 409, "message": "Обнаружены конфликты: …", "errors": ["…"], "details": { "issues": [ … ] } }
  ```

  `400` — ошибки валидации (перечислены поля), `401` — нет или истёк токен, `403` — недостаточно прав,
  `404` — объект не найден, `409` — конфликт расписания или состояния (например, повторное применение генерации).
- **Конфликты при правке**: создание, изменение, перенос, копирование и замена проверяются мгновенно; при блокирующих
  конфликтах возвращается `409` со списком `details.issues`. Диспетчер может повторить запрос с `force: true`
  (конфликт фиксируется предупреждением и попадает в проверку периода).
- **Доступ по ролям**: преподаватель и студент видят только опубликованные периоды; студент — только свою группу;
  преподаватель отмечает, отменяет и переносит только свои занятия, видит только свою нагрузку и контроль часов.

## Основные сценарии

| Сценарий | Запросы |
| --- | --- |
| Импорт учебного плана | `GET /programs/import-template` → `POST /programs/{id}/import` (multipart, поле `file`) → `GET /programs/{id}/curriculum` |
| Генерация | `POST /schedule-periods/{id}/generate` → опрос `GET /generation-jobs/{id}` → `POST /generation-jobs/{id}/apply` |
| Публикация | `POST /schedule-periods/{id}/validate` → `POST /schedule-periods/{id}/publish` |
| Отмена и отработка | `POST /schedule-lessons/{id}/cancel` → `GET /makeup-tasks/{id}/free-slots` → `POST /makeup-tasks/{id}/schedule` |
| Факт проведения | `POST /schedule-lessons/{id}/mark-conducted` (`actualHours` < плана — частично; `actualTeacherId` — заменяющий) |
| Контроль часов | `GET /hour-control`, `GET /hour-control/summary?by=group\|discipline\|teacher\|semester\|program\|college`, `GET /groups/{id}/hour-control`, `GET /programs/{id}/hour-control`, `GET /teachers/{id}/workload` |
| Отчёты | `GET /reports` → `GET /reports/{type}` → `GET /reports/{type}/export?format=xlsx\|pdf` |
